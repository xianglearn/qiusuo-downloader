# 求索下载 · 引擎下载说明

> 本目录（`bin/`）用于存放三个外部引擎的可执行文件。
> **引擎 exe 不进 Git 库**（第三方二进制、体积大、会更新），需按下表**手动下载**放入本目录。
> 发布时，主程序 exe 与这三个引擎 exe 必须放在同一目录。

---

## 三个引擎下载直达链接（Windows 版）

### ① GoDingtalk（钉钉群直播完整源引擎）
- **版本**：v2.5.2（最新）
- **下载**：https://github.com/NAXG/GoDingtalk/releases/download/v2.5.2/GoDingtalk_v2.5.2_windows_amd64.exe
- **放入文件**：`GoDingtalk_v2.5.2_windows_amd64.exe`
- **许可证**：MIT
- **备用入口**：https://github.com/NAXG/GoDingtalk/releases

### ② MediaGo（多平台通用解析引擎）
- **版本**：v0.3.0（最新）
- **下载**：https://github.com/Sophomoresty/mediago/releases/download/v0.3.0/mediago_0.3.0_windows_amd64.zip
- **解压后放入**：`mediago.exe`（zip 内为可执行文件）
- **许可证**：The Unlicense（公有领域）
- **备用入口**：https://github.com/Sophomoresty/mediago/releases

### ③ FFmpeg（分片合并/转码引擎）
- **说明**：FFmpeg 官方只提供源码，Windows 可执行文件需从第三方构建站获取。
- **推荐来源**：BtbN 构建站 https://github.com/BtbN/FFmpeg-Builds/releases（选最新 release 的 `ffmpeg-master-latest-win64-gpl.zip`，内含 ffmpeg.exe）
- **替代来源**：gyan.dev https://www.gyan.dev/ffmpeg/builds/（选 `release` 版完整包）
- **放入文件**：`ffmpeg.exe`
- **许可证**：GPL（再分发需遵守）
- **版本建议**：用最新稳定版（9.0.2 及以上），需实测支持 `-copyts -start_at_zero` 等参数

---

## 发布时文件清单（4 个文件同目录）

```
求索下载主程序.exe        （打包生成）
GoDingtalk_v2.5.2_windows_amd64.exe
mediago.exe
ffmpeg.exe
```

> ⚠️ 缺任一引擎，程序会提示"未找到下载引擎"且无法下载。

- 引擎会随各自项目持续更新，建议定期到各 Release 页确认最新版并替换。
- 三个引擎不是本项目的代码，是第三方编译好的二进制，分别遵循 MIT / Unlicense / GPL 许可证。
- 本说明文件随项目进 Git 库；**引擎 exe 本身不提交**（已在 `.gitignore` 中排除）。
