# Windows 更新超长暂停工具

一键把 Windows 自动更新暂停 **10,000 天**（约 27.4 年），点一下就行。

---

## 这是什么

Windows 自带的「暂停更新」最长只能选 **35 天**。本工具直接把「暂停到哪一天」
写进系统，把可选上限从默认的 5 周放宽到 **1428 周**。

界面上只有两个按钮：

| 按钮 | 作用 |
|---|---|
| **一键修改** | 暂停更新 10,000 天，截止约 2054 年 2 月 |
| **一键还原** | 清除全部暂停设置，恢复系统默认 |

## 直接使用

1. 下载本目录下的 `Windows更新超长暂停工具.exe`
2. 双击 → 系统弹出权限询问（UAC）→ 点「**是**」
3. 点「**一键修改**」
4. 程序会自动打开系统「设置 → Windows 更新」，显示
   「**更新已暂停，直到 2054 年 2 月 11 日**」
   把「暂停更新」那一项点开，可选周数已从 5 周变成 **1428 周**

想恢复：点「一键还原」即可。

完整说明见 [使用说明.txt](使用说明.txt)。

## 特点

- **纯 Python 标准库实现，零第三方依赖**
- 界面用 Windows 原生 API（`user32` / `gdi32`）手工绘制，
  **不依赖 WebView2、不依赖 VC++ 运行库**
- 打包后单个 exe 约 7.2 MB，换任何 Windows 10 / 11 机器直接能跑
- 首次运行会自动备份原始设置，随时可以一键还原
- 改动后会自动刷新系统「设置」程序，暂停状态立刻可见
  （实测发现「设置」只在启动那一刻读一次，不刷新的话页面上还是旧日期）
- 图标按分辨率分三档独立渲染，不是简单缩放同一张图：
  96px 以上带方向箭头、48/64px 只留圆环、40px 以下只留加粗竖条

## 源码与打包

| 文件 | 说明 |
|---|---|
| `main.py` | 单文件，含界面（纯 Win32 API）与业务逻辑 |
| `make_icon.py` | 图标生成脚本（需要 Pillow），产出 `app.ico` |
| `UpdatePauseTool.spec` | PyInstaller 打包配置 |
| `app.ico` | 应用图标，含 10 个尺寸 |
| `图标预览.png` | 图标各尺寸实际大小对照 |

```bash
pip install pillow pyinstaller
python make_icon.py                                   # 重新生成图标
pyinstaller --noconfirm --clean UpdatePauseTool.spec  # 打包
```

## 注意事项

- 本改法**微软官方并不支持**，官方文档写明的上限是 35 天。
  系统大版本更新后可能失效，重新点一下「一键修改」即可。
- 暂停期间月度安全补丁不会安装（杀毒软件病毒库是独立通道，仍会更新），
  长时间暂停意味着这台电脑长期没有安全补丁，请自行权衡。
- 设置页会附带一句「已达到最大暂停时间。为了帮助保护设备安全，请获取最新更新」
  —— 这是系统自带的固定提示，不是出错。
- 如果在设置页里手动选了「1428 周」，系统会把暂停期按整周取整
  （1428 × 7 = 9996 天，截止日期变成 2054 年 2 月 7 日），属正常现象。
- 点「一键修改」时如果你正开着系统「设置」窗口，它会被自动关闭再重新打开，
  这是正常现象，不是崩溃。
