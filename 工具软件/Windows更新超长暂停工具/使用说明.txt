Windows 更新超长暂停工具 — 使用说明
=====================================

一、这是什么
------------
点一下，把 Windows 更新暂停 10,000 天（约 27 年）。

界面上就两个按钮：
  · 一键修改  →  暂停更新 10,000 天
  · 一键还原  →  清除全部暂停设置，恢复系统默认

软件会直接把"暂停到哪一天"写进系统，然后自动帮你打开系统设置页面，
让你当场看到「更新已暂停，直到 2054 年 X 月 X 日」。

二、怎么用
----------
【暂停更新】
  1. 双击 exe，弹出系统权限询问（UAC），点「是」
  2. 点「一键修改」
  3. 等两三秒，系统「设置 → Windows 更新」会自动弹出来
     （万一没自动弹出来，就自己打开 设置 → Windows 更新）
      例如现在是2026年/9/26
     上面应该写着「更新已暂停，直到 2054 年 2 月 11 日」
     把"暂停更新"那一项点开，可选周数会从原来的 5 周变成 1428 周
  4. 核对完就可以关掉了，本软件也可以关掉

【还原（取消暂停）】
  点「一键还原」即可。所有跟暂停有关的项会被清除，
  系统恢复默认状态（默认状态下最长只能暂停 35 天），
  系统设置页同样会自动打开供你核对。

三、暂停多久
------------
固定 10,000 天 ≈ 27.4 年，截止日期可达1428周也就是27.4 年

在设置页把"暂停更新"那一项点开，能看到可选周数从系统默认的 5 周
变成了 1428 周（10000 ÷ 7 = 1428.57，向下取整就是 1428 周）。
这就是"暂停上限已被放宽"最直观的体现。

注意：如果在设置页里手动选了"1428 周"，系统会把暂停期改成整周数
（1428 × 7 = 9996 天，截止日期从 2054 年 2 月 11 日变成 2 月 7 日）——
这是 Windows 自己按周取整的行为，属于正常现象，不影响效果。

（选 10,000 天是因为：社区实测里，10,000 天是 Windows 设置界面还能正常
显示暂停日期的范围。填得再大，设置界面反而可能显示异常。）

特别注意：Windows 设置页在暂停期满时还会补一句
「已达到最大暂停时间。为了帮助保护设备安全，请获取最新更新」——
这是系统自带的固定提示，不是出错。

四、注意事项
------------
1. 必须用管理员权限运行。exe 已内置权限声明，双击时系统会自动弹出
   权限询问，点「是」即可。如果杀毒软件拦截，请选择"允许"。

2. 点「一键修改」时，如果你当时正开着系统「设置」窗口，它会被自动关闭
   再重新打开到 Windows 更新页 —— 这是正常现象，不是崩溃。

3. 这个改法微软官方并不支持。官方文档写明的上限是 35 天，
   我们是用注册表直接写日期实现的。系统大版本更新后可能失效，
   到时候重新点一下「一键修改」即可。

4. 暂停期间，月度安全补丁不会安装（杀毒软件的病毒库是独立通道，仍会更新）。
   长时间暂停意味着这台电脑长期没有安全补丁，请自行权衡。

5. 如果这是你第一次用，建议先手动建一个系统还原点：
   开始菜单搜索「创建还原点」→ 启用系统保护 → 创建。

五、跑不起来 / 没效果怎么办
---------------------------
· 提示"权限不足"      → 没以管理员身份运行，或杀软拦了权限
· 点完设置里没变化    → 关掉设置窗口重新打开一次；本工具的界面状态栏
                        会直接读出真实日期，以状态栏为准
· 其他问题            → 把界面上的提示原文发出来

六、开发者信息
--------------
开发环境：Python 3.13，无任何第三方依赖
源码文件：
  · main.py       — 单文件，含界面（纯 Win32 API）与注册表逻辑
  · make_icon.py  — 图标生成脚本（需要 Pillow），产出 app.ico
  · app.ico       — 应用图标（10 个尺寸：256/128/96/64/48/40/32/24/20/16）

暂停天数在 main.py 顶部的 PAUSE_DAYS 常量里改，改完重新打包：

  python make_icon.py            # 需要时重新生成图标
  pyinstaller --noconfirm --clean UpdatePauseTool.spec

图标按分辨率做了"渐进简化"，不是简单缩放同一张图：
  · 96px 以上 → 断口圆环 + 方向箭头（读作"更新循环被截停"）
  · 48/64px   → 只留断口圆环（箭头在这个尺寸会糊成噪点）
  · 40px 以下 → 只留加粗的暂停竖条（再小就糊成一团）
