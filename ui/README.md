# 求索下载 · UI 界面

重新设计的桌面端程序界面，单文件 HTML，可直接在浏览器中预览。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 完整界面（HTML + CSS + JS 单文件） |

## 快速预览

直接用浏览器打开 `index.html` 即可，无需构建、无需依赖。

```bash
# macOS / Linux
open ui/index.html

# Windows
start ui/index.html
```

## 界面特性

- **桌面程序窗口形态**：固定 960×640 初始尺寸，居中显示，带圆角和阴影，右下角可拖拽调整大小（最小 900×600）
- **深色 / 白色双主题**：标题栏月亮/太阳按钮一键切换，主题状态自动记忆
- **左侧批量导入区**：
  - 文本链接批量粘贴（支持钉钉回放/闪记/群文件 + B站/抖音/慕课等 90+ 平台）
  - 导入文本 / 导入二维码 / 清空
  - 批量采集复选框（多平台采集项）
  - 一键批量采集（自动识别当前群直播页，按群名保存）
- **右侧任务列表**：六列表格（文件名/大小/进度/速度/状态/操作），支持按状态筛选、全选
- **底部控制区**：总进度条、实时日志（4行显示，向下追加自动滚动）、开始/停止/解析/打开目录/重新登录/检查更新
- **设置弹窗**：保存目录、分片线程数、同时下载数、下载完成提示、自动检查更新

## 与主程序集成

当前为纯前端原型，所有按钮交互为模拟演示。接入实际程序时：

1. 将 `index.html` 作为 GUI 层嵌入（如 PyWebView / Electron / Tauri）
2. 按钮 `id` 即事件绑定点，在 JS 中替换为调用后端 API
3. 任务数据 `tasks` 数组替换为真实数据源
4. 日志 `addLog()` 函数接入程序 stdout
